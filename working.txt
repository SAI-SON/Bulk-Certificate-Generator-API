PROJECT OVERVIEW (திட்டத்தின் விளக்கம்):
--------------------------------------------------------------------------------
இந்த அப்ளிகேஷன் ஒரே நேரத்தில் நூற்றுக்கணக்கான அல்லது ஆயிரக்கணக்கான சர்டிபிகேட்டுகளை
(PDF) ரியல்-டைமில் பின்னணியில் (Background Worker - Celery) தயாரித்து வழங்கும் ஒரு
முழுமையான சிஸ்டம் ஆகும்.

தொழில்நுட்ப கட்டமைப்பு (Tech Stack):
- Web & API: Django 5.1 & Django REST Framework
- Database: PostgreSQL (Database name: 'demo' on port 5432)
- Broker / Cache: Redis (redis://localhost:6379/0)
- Task Worker: Celery 5.4 (with solo pool for Windows)
- Frontend: Real-Time SPA (HTML5, Modern CSS, Vanilla JS)


================================================================================
படி 1: சேவைகளைத் தொடங்குதல் (HOW TO START SERVICES)
================================================================================

1. டெர்மினல் 1 - Virtual Environment ஆக்டிவேட் செய்தல்:
   Command:
   .\venv\Scripts\activate

2. PostgreSQL & Redis இயங்குவதை உறுதி செய்தல்:
   - PostgreSQL 5432 போர்ட்டில் இயங்க வேண்டும்.
   - Redis 6379 போர்ட்டில் இயங்க வேண்டும்.

3. டெர்மினல் 2 - Celery Worker தொடங்குதல்:
   (Windows-ல் prefork பிரச்சினை வராமல் இருக்க --pool=solo கட்டாயம் பயன்படுத்த வேண்டும்)
   Command:
   .\venv\Scripts\celery.exe -A config worker --pool=solo -l INFO

4. டெர்மினல் 3 - Django Server தொடங்குதல்:
   Command:
   .\venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000

படி 3: அப்ளிகேஷனைப் பயன்படுத்தும் முறை (STEP-BY-STEP WORKFLOW)
================================================================================

முறை 1: 1-Click Demo Generation (விரைவான சோதனை முறை)
---------------------------------------------------
1. Dashboard பக்கத்தில் உள்ள "1-Click Demo Generation" பட்டனைக் கிளிக் செய்யவும்.
2. அப்ளிகேஷன் தானாகவே மாதிரி டேட்டாவை லோட் செய்து, வேலிடேட் செய்து, Celery மூலமாக
   சர்டிபிகேட்களை உருவாக்கத் தொடங்கும்.
3. ரியல்-டைம் Progress Bar 0% முதல் 100% வரை நகர்வதை பார்க்கலாம்.
4. முடிந்ததும் "Download All (ZIP)" கிளிக் செய்து அனைத்து PDF-களையும் ஒரே ZIP ஃபைலாக
   பதிவிறக்கலாம்.


முறை 2: உங்கள் சொந்த சர்டிபிகேட் டெம்ப்ளேட்டை உருவாக்குதல் (Template Studio)
--------------------------------------------------------------------------
1. மேலேயுள்ள "Template Studio" டேபிற்கு செல்லவும்.
2. Template Name கொடுக்கவும் (எ.கா: "Python Bootcamp 2026").
3. Background Image (PNG/JPEG) அப்லோட் செய்யவும் (Recommened: 1200 x 800 px).
4. Field Coordinates (JSON):
   சர்டிபிகேட்டில் பெயர், பாடத்தின் பெயர், தேதி, ID எந்த இடத்தில் (X, Y) வர வேண்டும்
   என்பதை JSON வடிவில் கொடுக்கவும்:
   {
     "name": { "x": 600, "y": 260, "font_size": 32, "color": "#1e293b", "align": "center" },
     "course_name": { "x": 600, "y": 430, "font_size": 22, "color": "#0f766e", "align": "center" },
     "completion_date": { "x": 950, "y": 590, "font_size": 16, "color": "#334155", "align": "center" },
     "certificate_id": { "x": 950, "y": 660, "font_size": 13, "color": "#64748b", "align": "center" }
   }
5. "Upload & Save Template" கிளிக் செய்து சேமிக்கவும்.


முறை 3: பேட்ச் ஜெனரேட்டர் (Batch Generator & Live Tracking)
-----------------------------------------------------------
1. "Real-Time Batch Generator" டேபிற்கு செல்லவும்.
2. Batch Name உள்ளிடவும் (எ.கா: "May 2026 Graduates").
3. நீங்கள் உருவாக்கிய Template-ஐ டிராப்-டவுனில் தேர்ந்தெடுக்கவும்.
4. பங்கேற்பாளர்களின் CSV ஃபைலை அப்லோட் செய்யவும்:
   (கட்டாய Header: name | விருப்ப Header: email, course_name, completion_date)
   
   மாதிரி CSV ஃபார்மேட்:
   --------------------------------------------------------------
   name,email,course_name,completion_date
   Sarah Connor,sarah@example.com,AI Engineering,2026-10-15
   John Wick,wick@example.com,AI Engineering,2026-10-15
   Priya Sharma,priya@example.com,AI Engineering,2026-10-15
   --------------------------------------------------------------

5. "Validate & Start Generation" பட்டனை கிளிக் செய்யவும்.
   - முதலில் கோப்பு வேலிடேட் செய்யப்படும் (தவறான ஈமெயில் அல்லது விடுபட்ட பெயர் சரிபார்க்கப்படும்).
   - அதன் பின் 20-க்கும் குறைவான பதிவுகள் என்றால் நேரடியாவும், அதிக பதிவுகள் என்றால்
     Celery Worker பின்னணியிலும் இயங்கும்.
   - திரையில் நேரடி Progress Bar, Success / Failed எண்ணிக்கை மற்றும் Event Log
     நிகழ்நேரத்தில் (Real-Time) மாறும்.
6. தயாரிப்பு முடிந்ததும்:
   - "Download All (ZIP)" பட்டனை கிளிக் செய்து மொத்த ஃபைல்களையும் பதிவிறக்கலாம்.
   - கீழே உள்ள பட்டியலில் தனித்தனி PDF-ஐ "View PDF" மூலமாக பார்க்கலாம்.


முறை 4: சர்டிபிகேட் உண்மைத்தன்மையை சரிபார்த்தல் (Public Verifier)
----------------------------------------------------------------
1. "Public Verifier" டேபிற்கு செல்லவும்.
2. ஜெனரேட் செய்யப்பட்ட சர்டிபிகேட்டின் ID-ஐ உள்ளிடவும் (எ.கா: CERT-2026-5YE795).
3. "Verify Certificate" கிளிக் செய்தால்:
   - சான்றிதழ் உண்மையானதா (Valid & Authenticated) என்று காட்டும்.
   - மாணவரின் பெயர், பாடப்பிரிவு மற்றும் வழங்கப்பட்ட தேதியை PostgreSQL-ல் இருந்து காட்டும்.


================================================================================
முக்கிய API Endpoints (API Reference for Developers)
================================================================================

1. Authentication:
   POST /api/v1/auth/login/         - பயனர் லாகின் (Token பெற)

2. Templates:
   GET  /api/v1/templates/          - டெம்ப்ளேட்கள் பட்டியல்
   POST /api/v1/templates/          - புதிய டெம்ப்ளேட் பதிவேற்றம்

3. Batches:
   GET  /api/v1/batches/            - பேட்ச்கள் பட்டியல்
   POST /api/v1/batches/            - புதிய பேட்ச் உருவாக்குதல்
   POST /api/v1/batches/{id}/validate/      - கோப்பை சரிபார்த்தல் (Validate)
   POST /api/v1/batches/{id}/generate/      - சர்டிபிகேட் தயாரிப்பை தொடங்குதல்
   GET  /api/v1/batches/{id}/status/        - நிகழ்நேர முன்னேற்றம் (Real-time progress)
   GET  /api/v1/batches/{id}/certificates/  - தயாரிக்கப்பட்ட சான்றிதழ்கள் பட்டியல்
   GET  /api/v1/batches/{id}/download-zip/  - மொத்த சான்றிதழ்கள் ZIP பதிவிறக்கம்

4. Public Verification:
   GET  /api/v1/verify/{certificate_id}/    - சான்றிதழ் உண்மைத்தன்மை சரிபார்ப்பு


================================================================================
5. டெம்ப்ளேட்டில் பெயரை மட்டும் மாற்றும் விதம் (SMART NAME POSITIONING & REPLACEMENT)
================================================================================

எந்தவொரு புதிய அல்லது பழைய சான்றிதழ் டெம்ப்ளேட்டாக இருந்தாலும், அதில் உள்ள பெயரை மட்டும் மாற்ற:

1. பிரவுசரில் http://127.0.0.1:8000/ திறந்து "Template Studio" டேபிற்கு செல்லவும்.
2. தற்போதுள்ள டெம்ப்ளேட்டை தேர்ந்தெடுக்கலாம் அல்லது "➕ Upload New Template" மூலம் உங்கள் புதிய சான்றிதழ் படத்தை (PNG/JPG) பதிவேற்றலாம்.
3. தானியங்கி முறை (Auto-Detect):
   - "✨ Auto-Detect Name Position" பட்டனை கிளிக் செய்தால், டெம்ப்ளேட்டின் அளவை அறிந்து சான்றிதழின் மையப்பகுதியில் பெயர் தானாக அமையும்.
4. க்ளிக் செய்து அமைக்கும் முறை (Visual Click-to-Position):
   - சான்றிதழ் படத்தில் பெயர் எங்கு வர வேண்டுமோ அங்கு நேரடியாக மவுஸால் க்ளிக் செய்யலாம் அல்லது டிராக் (Drag) செய்யலாம்.
5. பழைய போலி பெயர் / கோட்டை அழித்து புதிய பெயரை வைப்பது (Erase Placeholder):
   - "Clear/Erase Dummy Text or Line Under Name" ஆப்ஷனை டிக் செய்யவும்.
   - டெம்ப்ளேட்டில் ஏற்கனவே அச்சிடப்பட்டுள்ள பழைய போலி பெயர் அல்லது கோட்டை அழித்துவிட்டு, அதில் புதிய பங்கேற்பாளர் பெயர் மட்டுமே தூய்மையாக எழுதப்படும்.
6. "Save Configuration" கொடுத்தவுடன் மாற்றம் சேமிக்கப்பட்டு விடும்.
7. "Real-Time Batch Generator" டேபில் சென்று CSV ஃபைலை கொடுத்தவுடன், அனைத்து சான்றிதழ்களிலும் அந்த இடத்தில் துல்லியமாக பெயர்கள் மாற்றப்பட்டு PDF உருவாகும்!

பொதுவான சிக்கல்களும் தீர்வுகளும் (TROUBLESHOOTING)
================================================================================

1. Celery Worker பிழை:
   - Windows-ல் Celery இயக்கும்போது எப்போதும் `--pool=solo` என்பதை சேர்க்க வேண்டும்.

2. Database Connection பிழை:
   - PostgreSQL சர்வீஸ் இயங்குகிறதா என்பதை `pg_isready -h localhost -p 5432` மூலம் சோதிக்கவும்.
   - `.env` ஃபைலில் `USE_POSTGRES=True` உள்ளதை உறுதி செய்யவும்.

3. Redis Connection பிழை:
   - Redis இயங்குகிறதா என்பதை சோதிக்கவும் (Default: localhost:6379).
